# CCA2-Projects-Team-SJ-
This assignment focuses on collaborative AI and Machine Learning development using GitHub. Students work in groups to create repositories, upload ML files, create individual branches, commit their work, and submit pull requests. The assignment develops basic skills in GitHub, version control, teamwork, coding, documentation, and AI/ML applications.
